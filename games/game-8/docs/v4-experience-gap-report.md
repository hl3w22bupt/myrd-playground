### 2.2 桌面视口（1280×800，键盘）

- 满铺横屏画面：深灰纯色背景、绿色菱形目标物、像素牛头、**无任何场景装饰**。

## 三、四大体验差距清单（v4 定位依据）

> 每项三段式：**线上现状**（含证据）→ **v3 已实现未上线**（`bfce9152` 落账）→ **v4 验收口径建议**。

### ① 玩法多样性 —— 差距：结构性缺失

| | 内容 |
|---|---|
| 线上现状 | 单一目标物（青草垛 +1）；无道具、无 Combo、无波次；本局 0/20 口径为件数；整局数值曲线只有一条线性收紧 |
| v3 已实现 | 5 类目标物（normal +1 / rare +3 / clock +2 加时 4s / magnet 磁铁 100px·5s / boost ×1.5 速·4s）+ 波次权重表（稀有物占比随波次升高）；Combo 窗口 2s、加成封顶 +5、只作用于 ≥2 分高分物；3 波次状态机 + 波间停顿 1.2s + 波次横幅；同屏上限补齐制（≤6）；通关口径迁移为分数 |
| v4 建议 | **先上线 v3，再评估**：真机试玩后核对「追高分物的动力」与「波次切换的可感知性」是否达标；v3 的 magnet/boost 权重仅 2.5%~5%，可能出现「一局见不到道具」的体感，可作 v4 调参项（经调参面板，不改代码） |

### ② 画面品质 —— 差距：最直观的「朴素」

| | 内容 |
|---|---|
| 线上现状 | 纯深灰背景零装饰；目标物为单色菱形；牛牛为小尺寸像素牛头；结算面板纯文本两行；无粒子、无背景分层、无配色主题；**横屏画面在竖屏手机上上下大黑边（有效画面 ~27%）**（`mobile-02-initial.png`） |
| v3 已实现 | 分层背景 ≥2 层 + 统一配色主题；牛牛造型升级；5 类目标物专属造型（菱形/星形/八边形/U 形/闪电）与配色；收集粒子反馈；UI 主题化（开始/HUD/结算）；**竖屏适配（720×1280 基线）** |
| v4 建议 | 上线 v3 后在 375×812 / 390×844 真机复测黑边消除与安全区；审美层建议走 experience-review（advisory）对 v3 证据包出意见，避免 v4 盲目再改 |

### ③ 触屏可玩 —— 差距：操作模型单一 + 适配缺失（四维中体感最差）

| | 内容 |
|---|---|
| 线上现状 | 唯一触控入口 = 左下虚拟摇杆；**拖画布无效且无任何引导**（两次拖动牛牛未动，`mobile-06-after-drag.png`）；结算「确认」仅为右下角一行小字，无按钮视觉/触达区标识，直觉点面板区域无效；摇杆/游戏区被压在横条内，有效操作区域小；倒计时无缓冲即开跑 |
| v3 已实现 | 触屏拖拽与摇杆等效能力保留；竖屏视口适配 + 安全区（关键 UI 不被遮挡）；READY 开始面板（确认/触摸进入）解决倒计时抢跑；PAUSED 暂停入口 |
| v4 建议 | v3 上线后真机核对：① 拖拽与摇杆双通道都可控；② 开始面板后倒计时才起跑；③ 结算重开按钮触达区 ≥44×44px 且位置可发现。仍不达标才进 v4 |

### ④ 交互反馈 —— 差距：「零音效」实锤维持 + 正反馈三件套缺失

| | 内容 |
|---|---|
| 线上现状 | **整局零声音**：`__audioDebug` 显示壳层音频手势解锁器工作正常（mobile 点触后 state=running），但 `addModules=1`（仅引擎 AudioContext，无游戏音频内容）——与 v5 门禁经验「零音效」实锤一致；收集无粒子/飘字/屏幕震动等任何正反馈（本局 0/20 全程 HUD 无动态变化）；结算无新纪录强调 |
| v3 已实现 | `sfx.gd`（138 行，收集/波次/胜负音效链路，含首次手势解锁）；收集正反馈三件套（音效+粒子+飘字同帧触发）；新纪录高亮 |
| v4 建议 | v3 上线后真机（iOS Safari 优先）验证音效出声——**此项是历史双重踩坑区**（game 系列「移动端全部音效静默且控制台零报错」），必须真机取证，桌面仿真通过≠移动端通过 |
