## 一、试玩指引（怎么玩 · 看什么）

### 1.1 入口与环境
- **线上入口**：https://leomac-studio.tail49399e.ts.net/apps/game-8/ ——加载 ≤3 秒、无白屏/闪退/报错（验收硬线第 1 条）。
- **桌面**：浏览器直接打开；**移动端**：手机浏览器打开（竖屏 390×844 已仿真全绿；iOS Safari 真机音效仍是 D1 待实测项，桌面仿真通过 ≠ 真机出声）。
- 进入后先见**开始面板**（READY 阶段）：面板文案即目标说明——「60 秒内收集 20 分 / 青草垛 +1 · 金铃铛 +3 · 时钟 +2 并加时 / 连击高分物有加成 · 磁铁 / 加速帮你冲刺」。点击按钮或按确认键（Enter/Space）开始。

### 1.2 操作（对照用户拍板「触屏优先，兼容键盘」）
| 环境 | 移动 | 暂停 | 重开 |
|---|---|---|---|
| 键盘 | WASD + 方向键双套 8 向 | P | 结算面板 R / 按钮 |
| 触屏 | 屏幕内**虚拟摇杆**（左下，拖动 8 向） | 右上/顶部触屏暂停按钮 | 结算面板「再玩一局」按钮 |

- 触摸 UI 只在带触摸屏的环境显示，桌面键盘环境完全不可见（互不干扰）。
- 触屏卫生已上线：局内操作不会触发页面滚动、双击缩放或长按选中（壳页 gesturestart/dblclick preventDefault）。

### 1.3 局内看点（对照策划案 content）
1. **五类目标物**（触碰即消失、得分与类型一致、UI 同帧刷新）：
   | 类型 | 分值/效果 | 视觉 |
   |---|---|---|
   | 青草垛 normal | +1（恒 +1，吃不到 Combo 加成） | 草绿菱形 |
   | 金铃铛 rare | +3（吃 Combo 加成） | 亮金十点星 |
   | 时钟 clock | +2 且加时 +4s | 天蓝八边形 |
   | 磁铁 magnet | 道具：5s 内半径 100px 内计分物被吸来（拉速 170px/s） | 品红 U 形 |
   | 加速 boost | 道具：4s 内移速 ×1.5 | 青碧闪电 |
2. **Combo**：2 秒窗口内连续收集递增，断连/超时/重开清零；加成每级 +1 封顶 5，只作用于 ≥2 分高分物；连击音高逐级上行、飘字与粒子同帧。
3. **三波次**（波间停顿 1.2s + 横幅提示）：按分数切分 0-6 / 7-13 / 14-19，副标题「青草垛大量刷出」→「金铃铛变多」→「最后冲刺连击冲分」；越往后稀有物与道具占比越高、刷得越快（间隔 0.8s→0.45s、寿命 6s→3s，单调有界）。
4. **同屏上限** 6 件，低于上限由生成器补齐；物品临期 1.5s 内闪烁警示；过期自动回收**不计分**。
5. **反馈三件套**：收集=音效+粒子+飘字同帧；连击里程碑/道具生效/波次切换/胜负结算各有专属音效映射；关键事件叠加震屏（Camera2D）。
6. **画面**：牛牛多帧动画 3 组（待机/移动/收集），面朝转向翻转；分层背景+统一配色主题（风格卡：主 #3498db / 辅 #2ecc71 / 强调 #f39c12）。

### 1.4 结算与闭环
- **通关**：分数 ≥20 且未超时 → 立即停表结算「通关」；**失败**：时限归 0 且未达标 →「未达成」（失败也保留累计收集进度）。
- 结算页：胜负结论、本局得分 ÷ 目标、历史最高分与最高连击（刷新时金色「新纪录」高亮）；**一键重开按钮 + 键盘 R 双入口**；返回合集入口。
- 重开后立即可玩：得分归零、计时重置 60s、场上重铺、刷点避开出生点 ≥96px。
- **持久化**：退出重进，历史最高分/累计收集/最高连击不丢失（存 `user://niuniu_game8_save.json`）。

### 1.5 重点观察清单（v4 轮：四维升级是否可感）
1. 首分钟：开始面板文案能否让人不看说明就懂目标与操作？虚拟摇杆跟手吗？方向有没有反向？
2. 玩法深度：金铃铛/时钟出现时有没有「值得追」的感觉？磁铁/加速是否改变了走位决策？Combo 冲分是否有紧张感？
3. 画面：牛牛动画切换是否自然？波次横幅/粒子/震屏是否到位？风格与色板是否统一（对照风格卡：无像素风/黑描边/纯黑底/荧光色）？
4. 反馈：每次收集是否「音效+粒子+飘字」齐发？音量是否舒适（移动端注意 iOS 真机是否出声——D1 待实测）？
5. 节奏：60 秒一局内有没有明显断档/无聊段？波次停顿 1.2s 是节奏点还是打断感？
