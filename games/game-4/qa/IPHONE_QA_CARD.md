## ✅ 5 下回传（QA 实测报告，机判数据）

| 步骤 | 做什么 | 会看到什么 |
|---|---|---|
| ① | 点开上面的链接，等进度条走完（约 10–30 秒） | 左上角出现「🛠 QA 真机自检」面板，顶部有「QA 真机自检模式」徽标 |

| ④ | 在分享面板里点「**拷贝**」 | 面板关闭，报告已在剪贴板 |
| ⑤ | 切到频道「**光路谜阵 · 试玩反馈**」，长按输入框 → 粘贴 → 发送 | 频道里出现一段 `{...}` 开头的 JSON |

**这就完成了。** 最低门槛回传方式 = **把那段 JSON 粘贴到频道即可**（不用整理、不用截图也行）。
若分享面板里找不到「拷贝」：改点「存储到文件」或直接**截屏发频道**，都算有效回传。

报告里是什么（不用看懂，粘过来就行）：触屏命中率、旋转响应时延、声音是否出声、设备信息、
以及一行机判结论 `"verdict":{"pass":true|false,…}`。

## 📋 顺手填四问（可选，但对我们最有用）

1. 同一条链接，点左下角「**📋 试玩四问**」按钮（通关结算页也会浮出）。
2. 逐问点选：① 能/否 → ② 想再玩程度 1–5 → ③ 手感四维各 1–5 → ④ 有无断档。
3. 点「**提交并导出回传**」→ 分享面板「**拷贝**」→ 回频道粘贴发送。
4. 漏答会提示「还缺 N 项必答」，补上再点一次即可。

## ❓ 常见问题

- **没声音？** 点一下屏幕（iOS 要求先触碰才允许出声），报告里 `audio_context_state` 会显示 `running`。
- **进度条卡住？** 关掉重开链接，或切 Wi-Fi/蜂窝再试；wasm 首次加载约 30 MB。
- **转不动格子？** 点管件格子的中心；左下摇杆移动光标、右下「旋转」按钮也可操作。
- **星级怎么看？** 3 星 = 用最少步数通关；2 星 = ≤ 最优 ×1.5；1 星 = 通关。星级只升不降。
