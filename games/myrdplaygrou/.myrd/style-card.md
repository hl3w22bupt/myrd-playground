- scope: 植物人大战僵尸-网页版（games/myrdplaygrou，全局）
- applies-to: character / ui / tileset / sfx / 全场景视觉
- 依据：用户拍板的创作决策「美术风格：扁平明快（色板 #3498db/#2ecc71/#f39c12）」；硬约束「扁平色板：纯色块 + 简单几何造型，不使用渐变堆砌与写实素材」。风格参考图：无（用户未提供，本卡不设参考图段）。
- v2 修订：落 spec.numeric.visual.contrast 对比度规范 —— 草坪格底改低饱和深绿棋盘双档、
  前景主体统一 2px 描边 + 投影、HUD 换深底浅字；新增实体（向日葵/坚果墙）与僵尸头饰识别件。
- 用法：后续 UI、场景绘制、素材生成、美术评审一律对照本卡逐维度核对；与本卡冲突 = 风格缺陷。

- 饱和度倾向：中高饱和（S 55%~75%），明快不荧光；同一画面同屏色相 ≤ 5 种。
- 明度范围：色块明度 L 40%~68%（明快但不刺眼）；前景文字/描边统一用深色保证对比。
- **对比度硬规则（v2）**：前景主体填充 vs 所在格底、UI 文字/主色件 vs UI 深底，按 WCAG 2.x
  相对亮度公式实测 ≥3:1（声明色对表与机判见 `tests/smoke.gd` CONTRAST_PAIRS + docs §4）；
  分隔机制 = 2px 主体描边（`#1E3B25`）+ 投影 rgba(0,0,0,0.25) 偏移 2px。
- 规则：色板只准取上表及其同色系加深/提亮（明度 ±10% 内）；新增颜色必须先进本卡再用。

### ui（界面）

| 档位 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 标题 | 32px | 700 | 选关标题、胜负结算大字 |
| HUD 正文 | 20px | 400 | 阳光计数、波次进度、生命、按钮文字 |
| 辅助信息 | 14px | 400 | 操作提示、卡片费用/原因小字、结算副标题、常驻静音按钮 |

- 圆角半径：面板/按钮/卡片统一 8px；小徽标 4~6px；进度条直角。
- 描边：浅底面板 2px `#2C3E50`；深底 HUD 卡片 2px `#1E3B25`（选中 = 3px `#F1C40F` 阳光色）；
  无白描边、无双重描边。
- HUD 深底规范（v2）：顶栏 `#22313F` 平涂（无描边），文本 `#ECF0F1`，阳光数字 `#F1C40F`，
  主色件（出战卡）`#3498DB`，波次/重开按钮强调色，返回按钮中性色·深。
- 按钮三态（扁平立体：色块 + 深色 2px 描边，无投影渐变）：
  - normal：主色平涂；
  - hover：亮度 +8%；
  - pressed：文字下沉 3px、亮度 -6%（「按进去了」）；
  - disabled：中性灰 40% 不透明度（出战卡禁用态另加原因小字：冷却 Ns / 缺阳光）。
- 触屏优先：可点按控件最小 44×44px（含热区，spec input.minTouchTargetPx），间距 ≥ 8px；
  出战卡 84×48 两行式（短名 / 费用或原因）；键盘（WASD/方向键 + 空格/回车 + 1-5）与鼠标完全等价可用。
- 常驻件：右上角静音按钮（72×48，选关/对局/结算全程可见可点）。

### 形状语言（character / tileset / 动效）

- 形状词汇：圆角矩形 + 圆形 + 三角形拼装；植物 = 圆形头 + 圆角矩形茎叶 + 三角识别件；
  僵尸 = 圆角矩形身 + 圆头 + 前伸双臂矩形。
- 植物识别件（v2，全部 2px 描边 + 投影）：豌豆射手 = 绿圆头 + 右向嘴管；寒冰射手 = 蓝圆头 +
  头顶冰晶三角；双发射手 = 上下双嘴管；**向日葵 = 8 片阳光黄花瓣 + 橙色花盘 + 笑脸**；
  **坚果墙 = 高壮橙壳圆角矩形 + 深色壳纹 + 愁眉**。
- 僵尸识别件（v2：四类统一浅灰基底 `#BDC3C7`，识别色只上头饰且带 2px 描边）：
  路障 = 头顶橙色三角锥；铁桶 = 头顶深灰桶 + 桶沿；疾跑 = 暗红束带 + 前倾姿态 + 摆臂更急；
  普通 = 无头饰。
- 阳光拾取物 = 阳光黄圆盘 + 8 根旋转射线 + 高光点 + 2px 描边 + 投影；收集时「+N」飘字上浮。
- 线条：无手绘线条；仅 2px 深色描边或无描边色块拼接。
- 透视：纯侧视（僵尸沿横版 lane 从右向左推进），无等距、无伪 3D。
- 动效：位移、缩放（squash & stretch）、闪烁（modulate）三件套；缓动 outBack/outQuad；反馈一律走 Juice（pop/flash/shake/sfx）。
- 场景：左侧房屋防线（辅色几何块 + 章节色檐口）、右侧僵尸出生口（暗色透明矩形——纯色块，非渐变填充）、
  草坪 9×5 低饱和深绿棋盘双档按格交替；章节配色（晨绿/暮橙/夜蓝）落在天空底色 / 檐口 / 底部提示条。

## 反例（禁止）

- 渐变堆砌：任何 linear/radial gradient 按钮、天空、光效；玻璃拟态、光泽高光、内阴影。
- 写实素材：照片、手绘笔触、素描线、像素网格（pixel art）、3D 渲染图、描边粗细不一的卡通勾线。
- 色彩失控：低饱和暗黑夜景、霓虹配色、同屏超过 5 个色相、荧光色、色板外的临时取色。
- **对比度回归（v2 新增）**：前景主体与格底同色相/同明度带（v1「绿植物落亮绿草地不可见」教训）；
  主体缺描边或缺投影；僵尸识别色涂上躯干基底（识别色只上头饰）。
- 动效越界：旋转模糊、拖尾残影堆砌、粒子遮盖玩法信息。
- 触控反模式：小于 44px 的点按热区、依赖悬停（hover-only）才能触发的必经操作、需要键盘才能完成的必经操作。
