# style-card: flat-bright-pvz

- scope: 植物人大战僵尸-网页版（games/myrdplaygrou，全局）
- applies-to: character / ui / tileset / sfx / 全场景视觉
- 依据：用户拍板的创作决策「美术风格：扁平明快（色板 #3498db/#2ecc71/#f39c12）」；硬约束「扁平色板：纯色块 + 简单几何造型，不使用渐变堆砌与写实素材」。风格参考图：无（用户未提供，本卡不设参考图段）。
- 用法：后续 UI、场景绘制、素材生成、美术评审一律对照本卡逐维度核对；与本卡冲突 = 风格缺陷。

## 定义

### palette（配色）

| 角色 | HEX | 用途 |
|---|---|---|
| 主色 | `#2ECC71` | 草地主色、植物/防御单位主体、胜利态 |
| 主色·深 | `#27AE60` | 草地相邻行交替、按钮投影块 |
| 主色·亮 | `#58D68D` | 草地亮行、选中格高亮 |
| 辅色 | `#3498DB` | UI 面板、天空带、信息按钮、光标 |
| 辅色·深 | `#2980B9` | 辅色按钮投影、HUD 分隔 |
| 强调色 | `#F39C12` | 阳光资源、经济数字、卡片高亮 |
| 强调色·深 | `#E67E22` | 阳光描边、警告条 |
| 危险色 | `#E74C3C` | 僵尸威胁提示、失败态、生命扣减 |
| 中性色 | `#95A5A6` | 僵尸体色（灰绿调中性） |
| 中性色·深 | `#707B7C` | 僵尸暗部、禁用态 |
| 描边/文字 | `#2C3E50` | 全部描边与正文文字（单一描边色） |
| 浅底 | `#ECF0F1` | 面板浅底、卡片底 |

- 饱和度倾向：中高饱和（S 55%~75%），明快不荧光；同一画面同屏色相 ≤ 5 种。
- 明度范围：色块明度 L 40%~68%（明快但不刺眼）；文字/描边统一用深色 `#2C3E50`（L≈20%）保证对比。
- 规则：色板只准取上表及其同色系加深/提亮（明度 ±10% 内）；新增颜色必须先进本卡再用。

### ui（界面）

| 档位 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 标题 | 32px | 700 | 关卡开场「第 N 波」、胜负结算大字 |
| HUD 正文 | 20px | 400 | 阳光计数、波次进度、生命、按钮文字 |
| 辅助信息 | 14px | 400 | 操作提示、卡片费用小字、结算副标题 |

- 圆角半径：面板/按钮/卡片统一 8px；小徽标（费用气泡）4px；进度条直角。
- 描边：2px `#2C3E50`（或同色系加深色），全场景唯一描边色；无白描边、无双重描边。
- 按钮三态（扁平立体：色块 + 深色 2px 描边 + 底部 4px 同色系深色「硬投影」块）：
  - normal：主色平涂 + 硬投影；
  - hover：亮度 +8%（投影不变）；
  - pressed：整体下移 3px、硬投影消失（按进去了）、亮度 -6%；
  - disabled：中性灰 `#95A5A6` + 40% 不透明度、无投影。
- 触屏优先：可点按控件最小 48×48px（含热区），间距 ≥ 8px；HUD 按钮（静音/重开/开始）同样 48px 起；键盘（WASD/方向键 + 空格/回车）与鼠标完全等价可用。

### 形状语言（character / tileset / 动效）

- 形状词汇：圆角矩形 + 圆形 + 三角形拼装；角色 = 几何拼装（植物：圆形头 + 圆角矩形身 + 叶片三角；僵尸：圆角矩形身 + 圆头 + 前伸双臂矩形）。
- 种类识别件（全部色板内取色，形状语言不变）：路障僵尸 = 头顶橙色三角锥（强调色）；疾跑僵尸 = 深灰前倾身（中性色·深）；铁桶僵尸 = 头顶灰桶（中性色·深 + 描边）；寒冰系植物/弹丸 = 辅色蓝及同色系提亮 ≤10%；被减速僵尸 = 全身 modulate 蓝白罩染（渲染乘色，非新填色）。
- 线条：无手绘线条；仅 2px 深色描边或无描边色块拼接。
- 透视：纯侧视（僵尸沿横版 lane 从右向左推进），无等距、无伪 3D。
- 动效：位移、缩放（squash & stretch）、闪烁（modulate）三件套；缓动 outBack/outQuad；反馈一律走 Juice（pop/flash/shake/sfx）。
- 场景：左侧房屋防线（蓝色几何块）、右侧僵尸出生口（暗色渐隐矩形——纯色块，非渐变填充）、草坪 5 行相邻行交替双色。

## 反例（禁止）

- 渐变堆砌：任何 linear/radial gradient 按钮、天空、光效；玻璃拟态、光泽高光、内阴影。
- 写实素材：照片、手绘笔触、素描线、像素网格（pixel art）、3D 渲染图、描边粗细不一的卡通勾线。
- 色彩失控：低饱和暗黑夜景、霓虹配色、同屏超过 5 个色相、荧光色、色板外的临时取色。
- 动效越界：旋转模糊、拖尾残影堆砌、粒子遮盖玩法信息。
- 触控反模式：小于 44px 的点按热区、依赖悬停（hover-only）才能触发的必经操作、需要键盘才能完成的必经操作。
