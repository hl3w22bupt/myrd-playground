## 四、打回规则（N3 执行位：QA）

1. 缺 `build_version` → 打回（版本不可证=不可对账）；
2. 单人计数冒充样本（N<3）→ 不计轮；
3. F3/F4 原话缺失或为「感觉还行/还不错」类零信息量表述 → 该卡打回；
4. F3 与 a3 记录卡口径不一致（代拟原话/主持人诱导）→ 按 wheat-squad A3 判例整批作废；
5. 合格试玩 = **样本 ≥3 + 版本号 + F3/F4 原话 + QA verdict 齐**，缺一不计轮（N4 唯一裁决口径）。
