# style-card: football-flat-bright（实况足球 · GOAL RUSH）

- scope: myrdplaygrou-3（实况足球）
- applies-to: character / ui / tileset / sfx / music
- 来源：用户拍板创作决策「美术风格：扁平明快（色板 #3498db/#2ecc71/#f39c12）；触屏优先；竖屏；单局 1-3 分钟；难度平缓；BGM 与音效齐备」—— 本卡为该项目唯一风格锚点，生成提示词与 QA 检查都以它为准。
- 代码镜像：调色板唯一落点 `src/render/textures.js` PALETTE + `index.template.html` CSS 变量（preflight P2 / 场景同源纪律）。

## 定义

### palette（配色）
- 主色：#3498db（球员球衣 / 标题 / HUD 主强调 / 广告挡板）
- 辅色：#2ecc71（场地草绿 #2ecc71，条纹深绿 #27b463 同相减色；场外环带 #1d5c38 为其暗阶）
- 强调色：#f39c12（金币 / 守门员球衣 / CTA 与进球横幅 / 训练桩条纹）
- 中性：#ffffff（场地白线 / 门框 / 足球底色 #f5f5f5）、#dff2fb（天光背景）、#17313f（HUD 文字）、肤色 #f0c8a0
- 饱和度倾向：中高饱和扁平色块（无渐变叠加、无描边阴影堆叠）
- 明度范围：背景高明度（0.85+），场地中明度（0.55-0.65），角色中高明度（0.6-0.75）

### ui（界面）
- 圆角半径：12-14px（HUD 徽章 / 按钮 / 横幅统一 12px±2）
- 描边：2px 实线（chip 边框 var(--line)；横幅用强调色 2px）
- 按钮三态：常态=白底 82% 面板+主色描边；hover/active 不做（触屏优先，无 hover 态）；禁用态不出现（无禁用按钮）
- 字体层级：标题 38px/字距 6px 主色+白投影；正文 15px；HUD 数字 20px；CTA 18px 强调色 pulse 呼吸（1.6s）
- 热区：全部可点元素 ≥44px（暂停按钮 44×44）

### character（角色）
- 头身比：约 1:2.2（头 0.28-0.3 半径球 + 胶囊身，Q 版微缩比例）
- 线条：无描边（纯色块形体）
- 形状语言：圆润（胶囊+球头，零棱角）
- 比例参考：球员（主色蓝）与守门员（强调橙）同形体仅换色 —— 阵营靠颜色不靠形状

### tileset（场景块）
- 透视：固定高机位俯视（相机 y=26 后倾跟随机位，非正俯视也非等距）
- 像素密度：场地贴图 1024×1638 单张（不 repeat）；草地条纹 14 横条；白线宽 6px
- 接缝规则：场内/场外以白边线 + 蓝色广告挡板（0.9m 高）分界；挡板顶加 0.08m 白帽线

### sfx / music
- 乐器/波形：square（哨声/琶音主音）、triangle（BGM 铺底琶音）、sine（底鼓/暂停音）、白噪声+带通（射门/扑救摩擦质感）
- BPM：132（BGM 唯一节拍源，八分音符步长）
- 混响量：0（dry mix，总线仅 DynamicsCompressor）
- 响度基准：总线 gain 0.5；BGM 琶音 0.05-0.06（铺底不抢）；音效 0.15-0.32；哨声 0.15-0.18

## 形状语言
- 几何优先：圆柱（金币/训练桩/门柱）、胶囊（人形体）、球体（头/足球）、薄板（广告牌/网）—— 全部基本几何体程序化拼装，零外部模型
- 扁平着色：MeshStandardMaterial 低金属度（≤0.6）+ 高粗糙度（≥0.25），体积感靠光照不靠纹理渐变
- 发光语言：金币/光斑用 emissive + Bloom（UnrealBloomPass threshold 0.85），只点强调物不泛光
- 动画语言：自转（金币 z 轴 2.4rad/s、足球滚动）、往返巡逻（守门员三角波）、呼吸脉冲（CTA）—— 全部循环对称

## 反例（禁止）
- 禁止夜景/暗黑基调：模板默认的 #0a1014 深底、青色霓虹（#60cae0）已废弃 —— 本项目背景必须白天亮色（#dff2fb）
- 禁止色板外色相：紫/红/粉/青等不入画（草绿暗阶、肤白中性除外）
- 禁止写实贴图与照片素材：无 GLTF/FBX/位图加载（程序化 canvas 贴图除外，且只做条纹/斑点/渐变光斑）
- 禁止发光泛滥：Bloom 只点金币/光斑/横幅，禁止全场景泛光或辉光文字
- 禁止棱角角色：球员/守门员禁止方盒身/尖刺细节，保持胶囊+球头圆润语言
- 禁止外部资源引用：CDN/importmap/外链图片音频一律违反单文件契约（preflight P7 / singlefile 机判）
- 禁止描边+投影堆叠的「伪扁平」：UI 只允许 2px 描边，禁止 box-shadow 多层
