## 一、样本与执行

| 项 | 口径 |
|---|---|
| 样本 | **5 名真人**（主人圈定提名；机器不得代采、不得以模拟局顶替——retestProtocol②禁混算） |
| 单人流程 | 静默自由游玩 ≥15 分钟；主持人离席或后台记录；结束后 1v1 访谈（重开理由问询） |
| 时间窗 | 主人确认人选后 48h 内（窗口起止 ISO 时间戳可验真） |
| 设备 | 玩家自用手机/浏览器独立操作，不投屏不围观 |

## 二、防主持人污染设计（硬约束）

1. **统一开场白**（照读）：「随便玩，玩到你自己想停为止。」——禁止出现「重开」「再试一次」「指标」字眼。
2. 主持人全程**不演示、不提示、不坐近指点**；玩家卡死仅允许回应「按你的想法继续」。
3. 行为面以线上遥测 `restart_clicked{count,atMs}` 自动落账（附录旁证，不进判定），**判定以「玩家主动第二次开局」为准**：第 2 局开始时主持人必须不在玩家视线内。
4. 访谈在玩家结束后进行，问句：「你刚才为什么（没有）再开一局？」——只追问原话，不引导词库。

## 三、可判定观察点（逐条机判/可核验）

| 编号 | 观察点 | 判定方式 |
|---|---|---|
| O1 | 自然重开 ≥2 局 | 回填件记录第 2 局「玩家自主发起」勾选 + 时间戳；主持人位置声明（离席/后台） |
| O2 | 重开理由原话非空 | 回填件「理由原文」逐字留档（禁转述禁润色；拒答 = 「拒答」二字留档，不得代填） |
| O3 | 动机极性 | 原话编码：正向（想再试/想打更远/想换打法…）vs 负向（被要求/随便看看）；编码表随件，二人独立编码不一致时复核 |
| O4 | 局投入度下限 | 首局 ≥30s 或抵达 level-2 涌浪（防误触进样本） |

**达标判定**：满足 O1∧O2∧O3（且 O4）的人数 **≥4/5** → ac-a3 结论面 PASS。
