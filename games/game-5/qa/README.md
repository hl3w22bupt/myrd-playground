# games/game-5/qa/ —— 真机取证与试玩回填归档目录

> 本目录是《森林收集水果限时赛（game-5）》真机取证（需求 id=cmujot5ys0051m99i5t96onmo）
> 与用户试玩回填材料的**唯一归档位置**。本 README 只描述通道与格式约定，不含任何实测结论 ——
> 结论只能来自用户本人亲手操作，agent 不得代做、不得伪造。

## 一、归档物清单（对应需求验收标准）

| # | 归档物 | 验收标准来源 | 建议文件名 |
| --- | --- | --- | --- |
| 1 | iOS Safari 真机核心操作取证（截图/录屏，能看出松鼠随摇杆/触屏位移） | 验收 1 | `game5-joystick-<日期>.jpg|mp4` |
| 2 | 真机音效取证（含声音的录屏，或 AudioContext.state='running' 截图 + 人耳听感结论） | 验收 2 | `game5-audio-<日期>.jpg|mp4` |
| 3 | 设备数据归档（验收中枢页一键导出的 markdown，只含原始读数 + 来源标记） | 需求 §一-3 | `game5-device-evidence-<日期>-<时分>.md` |
| 4 | 试玩量表回填文档（五维 1~5 分 + 一句理由 + 调参反馈 + 署名） | 验收 3 | `game5-playtest-survey-<日期>-<时分>.md` |

## 二、文件名与说明行约定

- 文件名一律带日期：`game5-<主题>-YYYYMMDD[-HHMM].<ext>`。
- 每份截图/录屏**必须附一行文字说明**，包含五要素：
  `设备型号 / iOS 版本 / 实测时间 / 操作项 / 用户本人的结论`。
  示例（仅为格式示例，内容必须照实填写）：
  `iPhone 15 / iOS 17.5 / 2026-09-27 19:30 / 左下摇杆推右上→左下各 3 秒 / （结论由试玩人填写）`

## 三、入口与取证工具

- 游戏地址（liveUrl）：https://leomac-studio.tail49399e.ts.net/apps/game-5/
- 验收中枢页（hubUrl）：https://leomac-studio.tail49399e.ts.net/apps/game-5/?hub=1
  （或游戏内点「验收中枢」按钮 / 按 H 键）
- 调参工作台：https://leomac-studio.tail49399e.ts.net/apps/game-5/?tuning=1

中枢页提供：liveUrl 二维码（iPhone 相机扫码直达）、真机取证分步引导（复制归档说明）、
设备数据一键导出（每项读数带来源标记，如 `navigator.userAgent`、`window.__audioDebug__()`，
取不到的读数如实标注「未采集」，文档本身不含任何判定）、五维量表回填表单
（五维分数与理由、署名全部填写后才允许导出）。

## 四、红线（需求原文固化）

1. agent 只负责搭建试玩/调参入口与 qa 归档通道，**不代做、不伪造**任何真机/试玩结论。
2. 用户未完成前，相关需求状态如实挂账「等待用户」，目录里不得出现 agent 生成的
   "实测结果"、"试玩结论" 类文件。
3. 全部归档材料必须可溯源：设备数据文档自带来源标记；量表文档自带署名与导出时间。
