# 音效素材来源与许可

全部 `.wav` 取自 Juhani Junkala《The Essential Retro Video Game Sound Effects Collection [512 sounds]》，
原作者以 **CC0 1.0（公有领域贡献）** 发布 —— 「You can do anything you want with these sounds」，
可免费商用、无需署名（本文件为善意溯源，非许可义务）。

- 来源页：https://opengameart.org/content/512-sound-effects-8-bit-style
- 原始格式：44100Hz / 16bit / 单声道 WAV（未做重采样，仅按用途改名列出）

| 文件 | 事件 | 原始文件 |
| --- | --- | --- |
| `swap.wav` | 滑动/点按交换糖果 | `General Sounds/Menu Sounds/sfx_menu_move2.wav` |
| `select.wav` | 点按选中糖果 | `General Sounds/Menu Sounds/sfx_menu_select1.wav` |
| `match.wav` | 消除收集 | `General Sounds/Coins/sfx_coin_double1.wav` |
| `combo.wav` | 连锁（第 2 波起） | `General Sounds/Positive Sounds/sfx_sounds_powerup12.wav` |
| `win.wav` | 过关/胜利 | `General Sounds/Fanfares/sfx_sounds_fanfare1.wav` |
| `lose.wav` | 步数耗尽/失败 | `General Sounds/Negative Sounds/sfx_sounds_negative1.wav` |

| `click.wav` | UI 按钮点按 | `General Sounds/Buttons/sfx_sounds_button6.wav` |
