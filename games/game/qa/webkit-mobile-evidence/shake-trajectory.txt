无效交换抖动/回弹定量轨迹（真 WebKit webkit-2359 · iPhone 13 描述符 390x664@3x · 线上 v13 部署）
================================================================================
对象：交换对 (1,3)→(1,4) 的涉事糖果；(1,3)=蓝色糖果、(1,4)=红色糖果。
无效交换不换糖果（try_swap 失败原样换回），红闪框出现在 tapB 目标格 (1,4)。
测量窗口：格心 x=120.2（CSS px），视频 10fps 抽帧（8.48s 全程）。
质心偏移 = 糖果色块质心 x − 120.2；n = 色块像素数（面积 ∝ scale²）。

与 board.gd 设计参数对照：
- INVALID_SHRINK_SCALE = 0.72 → 面积比 0.72² ≈ 0.52；实测 632/921 ≈ 0.69（含抗锯齿边缘损失，量级吻合）
- INVALID_SHAKE_AMPS = [8,6,4,2] 设计px（±4.15~1.0 CSS px）→ 实测摆幅 2.66→2.28→2.20→0.72（逐段衰减 ✓）
- INVALID_FX_SEC = 0.5s（0.08 缩小 + 4×0.07 抖动 + 0.14 回弹）→ 实测 6.35s 触发、6.8s 归位（10fps 抽帧下 4 帧覆盖 ✓）
- 无效不耗步：MOVES 停留 19（对照 frame043 有效交换 SCORE 60、MOVES 20→19）
- HUD 大字提示停留 2.5s（INVALID_MSG_HOLD_SEC）：f_0065 与 f_0067 均可见

结论：无效交换在真 WebKit 移动端触发「缩小 → 衰减抖动 → 回弹归位」动画 + 红闪框 +
加大字号 HUD 提示，三重反馈与代码设计一致，玩家可感知。
