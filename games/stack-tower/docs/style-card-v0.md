# Stack Tower 风格卡 v0（T3 美术线）

> 版本：v0 骨架（2026-09-25） · 负责人：游戏美术（T3） · 锚定：spec v1 world 段文本（`.myrd/spec/design-spec.json` → `spec.world`）
> 零编造声明：本卡所有主题项派生自 spec.world.logline / art_style（黄昏工地 · 吊臂 · 混凝土块 · 切面 · 塔身涟漪），不引入外部 IP 与无出处意象。
> 升版触发：主人对首屏构图或色板给出方向性意见 → 30 分钟内升 v1（版本链在文末）。

## 0. 主题锚点（照抄 spec.world，唯一上游）
> 「黄昏的工地上没有起重机，只有你和一个不知疲倦的吊臂：混凝土块在塔顶左右摆荡，你要在它与塔身对齐的一瞬放手——切面留下的每一道错口都是塔的年轮，而完美的一击会让整座塔泛起一圈涟漪。」
> art_style：冷灰蓝黄昏天空 + 暖色系塔块（陶土橙/砖红/沙黄循环）+ 白色切面高亮；全资产程序化，零外部资源。

## 1. 光照逻辑
- **单一主光**：正午偏西的顶光（模拟吊臂上方工地照明），塔块顶面最亮、正面次之、底面最暗（三面明度比 100 : 78 : 55）。
- **层递减**：塔身自上而下每层明度 −2%（近似整体 −8%/5 层的读数感），底部渐沉入暮色——强化「越叠越高」的目标感（renderer.ts `shade = max(0.55, 1 − yIndex×0.02)` 已固化）。
- **反弹光**：地面/已落块对摆动块底部给一道冷灰蓝反弹（天光色），把「即将落下的块」从背景里托出来。
- **特殊时刻光**：tower-ripple 触发时**不加光源**——只走波纹描边透明度（1→0）与白色切面描边脉冲，保持「完美=克制」的反馈哲学（T1 必改②降维决议的光照表达）。

## 2. 对比度策略
- **主对比**：暖色塔块（高饱和陶土橙系）vs 冷灰蓝天幕（低饱和）——色相差 ≈150°，首屏一眼分清「可玩物 vs 背景」。
- **功能对比**：白色切面高亮描边（1px, α0.85）只出现在块边缘——它是判定物，视觉上必须「最细但最醒目」；掉落碎块用 α0.25 黑，明确「已失败、离开可玩域」。
- **HUD 对比**：白字 + 深色描边（无底板，不遮塔）；数字用等宽体防跳动。
- **可读性红线**：摆动块与已落块同层并列时，明度差 ≥15%；天空任意位置的渐变明度不得进入塔块明度区间（±10%）。
- **无障碍留槽**：色盲模式（暖色系 → 明度阶梯方案）v1 再议，见 §5。

## 3. 构图脚本模板（首屏，可参数化复用到升版）

```
镜头：固定竖构图 480×720（逻辑像素），无滚镜（塔高用镜头微上移表达：每 +5 层上移 0.5 层高，缓动 300ms）
L0 背景  ：天空线性渐变 #2b3a4d → #8a97a8（顶到底），远景 2~3 道工地塔吊剪影（α0.18，程序化折线）
L1 地平线：y=640 处一条 1px 暮色线（#a08c6a, α0.4），不与塔基重叠
L2 塔身  ：塔基中心 x=240，自 y=692 向上堆叠；已落块暖色三循环 + 层明度递减；切面白描边
L3 摆动块：悬停带 y≈692−(layers+2)×28；块下缘一道冷灰蓝反弹光（#8a97a8, α0.35）
L4 引导层：首局且 layers<2 时，摆动块正下方显示落点虚线参考（α0.3，玩家完成 2 次落块后淡出）
L5 HUD   ：顶栏（分数/连击/关卡进度）+ 底部重开入口；白字深描边，高 56px 安全区
L6 反馈层：tower-ripple 波纹（椭圆描边，300±50ms，1→0 淡出）+ 完美叮音；无整屏闪光
```

- 首屏 0.5s 静读测试：玩家应能在 0.5s 内回答「哪里是塔 / 哪里是摆块 / 该点什么」——升 v1 时用截图走查验证。
- 构图脚本与实现映射：L0/L2/L3/L6 已在 `src/render/renderer.ts` 落地；L4/L5 随实现冲刺（hud.ts / 引导层）。

## 4. 资产重量预算（<300KB，程序化优先）

| 项 | 预算 | 生成方式 | 现状 |
|---|---|---|---|
| 天空/背景层 | ≤8KB | Canvas2D 渐变 + 折线剪影（代码即资产） | renderer.ts 已落 |
| 塔块/摆块 | ≤4KB | 纯几何 + 描边（无贴图） | renderer.ts 已落 |
| 波纹/碎块 | ≤2KB | 描边动画 | renderer.ts 已落 |
| 音效 ×3 | ≤6KB 源码 | WebAudio 合成（振荡器+包络） | 实现冲刺 |
| 字体 | 0（系统等宽栈） | CSS font-family | — |
| **总计** | **≤20KB 源码级** | **远低于 300KB 上限** | — |

红线：任何单资产（贴图/音频样本）>50KB 或引入外部下载 → 必须回本卡重新过预算；风格升级优先「代码化生成」而非「素材导入」。

### 6.2 预算与门禁自证
- 实测 **9 资产共 29.19KB**（单资产最大 16.48KB），远低于 §4 的 300KB 总预算与 50KB 单资产红线；生成器超限即非零退出。
- 复现：`node games/stack-tower/tools/gen-assets.mjs`（确定性：重复运行逐字节一致）。
- 接线门禁：`node games/stack-tower/tests/assets-check.mjs` 三态 —— 浏览器级（运行时 9/9 请求 200 + 「贴图就绪 9/9」+ 零页面错误 + **资产全 404 负面用例核心循环仍可玩**）/ 降级（静态可达 + PNG 签名）/ FAIL。
- fallback 纪律：`src/render/assets.ts` 无加载器（Node 契约测试）→ 空清单；加载失败 → 该项 null → 程序化绘制；任何情况不抛错、不刷 console.error。
