## 三、首屏构图脚本（与 style-card §3 同一份真源，此处为美术视角速览）

```
0.0s  天空渐变铺满 480×720，塔吊剪影 2~3 道静置远景（α0.18）
0.0s  塔基块立于画面下 1/4 中轴（x=240），暖色三循环首色，白描边
0.2s  摆动块自中轴左侧入画，沿悬停带 160px/s 右移，下缘反弹光
持续  玩家点击 → 块落 → 切面错口定格 →（若 perfect）波纹自塔顶扩散 300ms
 Hud  顶栏白字：分数 / 连击 ×n / 关卡进度；底部重开入口常驻
```

情绪目标：前 3 秒让玩家读出「就一个动作——在对齐的一瞬点下去」；第 1 次 perfect 的波纹是本卡唯一的「高光时刻」，必须克制而清晰。
