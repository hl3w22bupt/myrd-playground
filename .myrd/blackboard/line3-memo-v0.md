## 二、程序产线盘点输入（TS+Canvas vs Godot · 仓内实证，2026-10-15）

| 维度 | TS+Canvas（g2-blocks / wheat-squad 判例） | Godot（game-8 / game-9 判例） |
|---|---|---|
| 冷启动 | **≈0 依赖**：零 npm 依赖 + `stripTypeScriptTypes` 构建判例；预置件 `templates/next-line-scaffold`（B2 判例空壳冒烟 4/4）→ 当轮可出可玩骨架 | 技能三件套已固化（preflight.py 583 行 / gate-selftest.sh 350 行 / smoke.sh + resolve-godot.sh）+ 模板 minimal-2d（含 2.9MB 字体）→ 起手成本已压缩但仍需引擎解析与模板装配 |
| 门禁面 | **确定性 headless 契约体系成熟**：16 条 ac 契约可 headless 逐条机判（同 seed 逐字节一致 det-1 判例）+ 五步 verify.sh 一键门禁 + 统一契约器 approved 对账 | GODOT_SMOKE（帧预算 + 退出码 + 零 SCRIPT ERROR）——可机判但**无逐字节确定性断言判例**；好玩判据 auto 面弱于 TS 线 |
| 复用度 | 消除（g2-blocks）× 放置割草（wheat-squad）两线验证；同屏实体性能契约（perf-1 机型档）模板现成 | 连连看（game-9）× 牧场收集（game-8）两线验证；摇杆/触屏/多分辨率适配判例现成；物理/3D 面未验证 |
| 部署面 | AppHost 双坑现成（g2-blocks-2 v17 / wheat-squad-2 v17）· 确定性重建 + sha 注入指纹判例（本轮新建） | game-9 独立坑 v5 在档；打包链路不同（引擎产物 bundle） |
| 结论 | **快迭代 + 确定性机判 + IAA 休闲轻玩法 = 首选产线**；线 3 若选轻玩法休闲品类默认沿 TS+Canvas | 仅当候选强依赖引擎能力（物理/复杂动效/3D）时启用；启用即接受门禁面降级（确定性断言弱） |

## 三、候选清单（5 条 · 逐条标「视觉可观察」· 硬排除件另列）

### 硬排除清单（品类纪律执行记录）

| 排除项 | 理由 |
|---|---|
| 割草生存 survivor-like 新变体 | 与线 2 同品类（wheat-squad 在研，R1 复测收口中） |
| 合成类（2048-like / merge 龙 / 合成大西瓜形态） | 任务书品类纪律字面硬排（合成） |
| 堆叠类（stack tower 变体） | 与 stack-tower 冻结线同款（同大类红线延续） |
| 消除 match-3 直系变体 | 与线 1 同款（非变体不列；变体见候选 5 标注） |

### 候选 1 · 单场景塔防（炮塔防守 · 波次切面）

- 一句话：关卡制布防 + 波次防守 + 轻升级，单场景波次切面起步（简报 C3）。
- 支撑数据：D1（塔防形态微信畅销头部验证）· D7（抖音休闲盘）· D10（IAA 分成）。
- 产线适配：**TS+Canvas 高复用**（波次状态机/实体上限/确定性仿真全部有 wheat-squad 判例；perf 契约直接复用）。
- 品类纪律：无冲突（与线 1/2、stack-tower、game-8/9 均错开）。
- **视觉可观察：是** → 四要素落点：**色板**（塔阶色阶 × palette 8 色内）；**比例**（射程圈/网格占比规范）。光照/线条可后补（风格卡预研时定）。
- 风险：关卡设计成本高（简报已列）——首批切「单场景波次」降内容消耗。

### 候选 2 · IO 对撞大乱斗（AI 代打局形态）

- 一句话：摇杆移动 + 吞并成长 + 局内排行，真联机以「AI 代打局」降级（简报 C4）。
- 支撑数据：D2（微信人气榜休闲向形态）· D7（抖音休闲占比超四成）。
- 产线适配：TS+Canvas 中复用（摇杆/触屏判例在 Godot 线，TS 面需补；实体碰撞仿真有判例）。
- 品类纪律：无冲突。
- **视觉可观察：是** → 四要素落点：**色板**（阵营色块区分）；**比例**（成长体型曲线/体型-等级映射规范）。
- 风险：留存弱于塔防（简报 D2 面数据无留存佐证 → 自动降权半档）。

### 候选 3 · 轻模拟经营（单场景 + 离线收益 · 女性向包装可选）

- 一句话：单场景经营循环 + 离线收益 + 目标链（简报 C2）。
- 支撑数据：D4（模拟经营/女性向份额增速加快）· D7（抖音 TOP10 经营模拟）· D8（内购倾斜=长线空间）。
- 产线适配：**TS+Canvas 低复用**（数值链长、内容消耗快——简报原判「产线复用率较低」）；Godot 亦无优势。
- 品类纪律：⚠️ **标注**：与线 2「局外放置收益成长」面部分重叠（wheat-squad oneLiner 含放置收益）——若选此候选须出「机制差异点声明」（经营链主体 vs 割草局内主体）才可立项。
- **视觉可观察：是** → 四要素落点：**光照**（昼夜/时段氛围切换）；**比例**（场景功能分区布局规范）。
- 风险：美术产能要求最高（简报原判）；内容驱动 = 确定性机判面最弱。

### 候选 4 · 弹射角度类（「一箭又一箭/箭头会拐弯」形态）

- 一句话：角度/力度弹射 + 弹道反弹解谜 + 关卡递进（微信畅玩榜在档形态，D3）。
- 支撑数据：D3（微信畅玩榜《一箭又一箭》《箭头会拐弯》在列，引力引擎 2026-04）· D5/D10（IAA 红利）。
- 产线适配：TS+Canvas 高复用（确定性弹道仿真 = 现有内核强项；det-1 逐字节断言直接适配）。
- 品类纪律：无冲突（弹射 ≠ 堆叠/消除/割草）。
- **视觉可观察：是** → 四要素落点：**线条**（弹道虚线/瞄准线规范）；**比例**（力度条/角度盘 UI 占比）。
- 风险：关卡内容消耗快（与塔防同款风险，切「程序化关卡生成 + 种子确定性」可解——恰是产线强项）。

### 候选 5 · 链式消除（hexa/链式变体）——「与线 1 大类近」标注件

- 一句话：链式连接消除 + 连击计分（非 match-3 直系）。
- 品类纪律：⚠️ **标注「与线 1 大类近」**（消除大类变体，任务书纪律要求显式标注）；列示仅作对照项，**不作首发推荐**（品类密度 + 线 1 在提审流程中）。
- **视觉可观察：是** → 四要素落点：**色板**（链色阶）+ 粒子（消除爆点）。
- 产线适配：TS+Canvas 高复用（g2-blocks 全套判例）——正因复用度高、差异化低，策划面不推荐。
