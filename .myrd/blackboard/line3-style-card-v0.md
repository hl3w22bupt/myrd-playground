## 四要素

### 1. 调色板（palette · 8 色结构占位，色值待主人拍板后冻结）

| 角色 | 占位方向 | 说明 |
|---|---|---|
| 底色 ground | 低饱和暖灰（麦土色系） | 战场底，读数不抢戏 |
| 路径 path | 深一档暖灰 | 敌军动线一眼可读（塔防第一视觉语言） |
| 主塔 primary | 高饱和青绿 | 玩家操作主体，最高对比 |
| 升级阶 2/3 | 同色相提亮两档 | 等级=亮度阶梯，零新色相 |
| 敌军 hostile | 高对比赭红 | 与主塔色相对立，混战不糊 |
| 弹丸/特效 fx | 暖白 + 主塔色 | 复用通道（wheat-squad fx 三件判例同构） |
| UI 面板 | 近白/近黑双档 | 轻拟物，字压对比 ≥4.5:1 |
| 警示 danger | 琥珀 | 核心据点低血量/漏怪提示专用 |

### 2. 光照

无动态光照——**平面色块 + 两档明度投影**（实体脚下 1px 偏移暗色椭圆，程序化绘制）；核心据点呼吸光带仅用主塔色 alpha 脉冲（确定性面：光效参数进 token，非逐帧随机）。

### 3. 线条

统一 2px 圆头描边（敌军动线箭头 / 射程圈 / 网格布防位高亮共用一根线宽 token）；射程圈=虚线（dash 8/6），选中布防位=实线加亮；**禁止渐变描边**（确定性渲染 + 截图比对可机判）。

### 4. 比例

网格 32px 基准（390×640 竖屏 → 12×14 可布防区）；炮塔占 1 格（32px），敌军 24px 内切圆，核心据点 48px；射程圈半径 = 2.5/3.5/4.5 格三档（对应塔 1-3 级）；HUD 上带 ≤64px、下带 ≤96px（承两线安全区判例）。

## 生成纪律（建工程轮执行）

- theme.ts token 单源 → 程序化生成器逐件产出 → manifest 逐件 hash → 重生成 hash 不变验证确定性（wheat-squad deterministic-asset-pipeline 判例平移）。
- 首批件数按 memo v0/B3 档位：**10-12 件**封顶（地块/塔 3 阶/敌 3 型/弹丸/UI）。
- 正式视觉（是否三国题材/治愈方向/具体色值）= **主人拍板项**，拍板前零图零冻结。
