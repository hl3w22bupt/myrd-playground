## 口径声明（红线④）

- **本口径不进 spec acceptance**：中端机 60fps / P95 ≤ 16.7ms 落发布就绪清单。
- 采样 = requestAnimationFrame 相邻回调时间差（含掉帧），环形缓冲 600 帧。
- 掉帧口径：单帧 > 20ms（60fps 预算 16.7ms 的 1.2 倍）记一次卡顿。
- **代理披露**：headless 桌面 Chrome 不是中端真机；基准跑（throttle×1）是本环境能给的最好代理，
  规格跑（throttle×4）仅用于与 spec J1 同环境对照，**不应**用 16.7ms 去判它。
