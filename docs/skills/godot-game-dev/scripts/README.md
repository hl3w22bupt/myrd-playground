源头以 `std-skills/godot-game-dev/scripts/` 为准；两处必须保持同步，修改只落在 std-skills 后再复制过来。
验证命令：`python3 docs/skills/godot-game-dev/scripts/preflight.py games/game` 与 `bash docs/skills/godot-game-dev/scripts/smoke.sh games/game`。
