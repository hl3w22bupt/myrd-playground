## 0. 设计定位与体验目标

| 维度 | 结论 |
|---|---|
| 品类 | 休闲经营（放置式田园经营），单机、本地存档、纯浏览器可玩 |
| 核心情绪 | 治愈、轻松、有成长目标感；零挫败、零时间惩罚 |
| 核心循环时长 | 首个完整闭环 ≤ 2.5 分钟；单轮「种/养 → 收 → 售」2~3 分钟 |
| 会话目标 | 10 分钟连续试玩内完成：引导 → 解锁鸡舍 → 建成工坊 → 解锁休闲天地 |
| 非目标（v1 裁剪） | 不做联网/排行榜/内购/离线收益结算；不做多存档位 |

**体验支柱（三条，所有取舍以此裁决）**
1. **永远有事做，但永远不催你**：任何时刻都有 ≥1 个可进行的生产动作与 ≥1 个可领取目标，但没有倒计时惩罚。
2. **数字看得见地变大**：金币/经验/产出的每次增长都有动效与音效反馈，升级曲线在 10 分钟内至少被感知 3 次。
3. **画面即治愈**：低饱和暖色 + 柔和光照 + 自然白噪音，任何交互不允许出现刺耳音效或高对比闪烁。

## 1. 经营循环（核心闭环）

```
        ┌──────────── 再投入（扩建地块 / 建造升级设施）◄──────────┐
        │                                                        │
  开垦/建造 → 投入（播种/投喂/放原料）→ 等待生长/生产 → 收获/取产出
                                                      │
                              加工（工坊：原料 → 高价商品）│
                                                      ▼
                          售卖（集市直售 / 订单交付：金币 + 经验）─┘
```

### 1.1 三条并行生产线（对应三大生产区域）

| 线 | 区域 | 节奏 | 定位 |
|---|---|---|---|
| 种植 | z1 菜园 | 20s~360s/茬，短平快，现金流主力 | 新手期唯一收入，全程基础盘 |
| 花卉 | z4 小花园 | 60s~300s/株，单株高价低量 | 订单高价值原料，中后期利润放大器 |
| 养殖+加工 | z3 禽舍 → 工坊位 | 鸡 60s/枚蛋，蛋可直售或加工蛋糕 | 持续被动产出 + 增值加工，长线收益 |
| 果树 | z2 果园 | 300s~480s/轮，永久设施 | 大额一次投入、长期稳定回报 |
| 增益 | z5 休闲天地 | 一次性建造 | 只产增益不产原料（刷新加速/售价加成/经验加成），是「再投入」的情绪出口 |

### 1.2 首个闭环脚本（新手引导走此路径，ac5 依据）

1. 进入庭院，HUD 引导高亮「仓库/金币/任务」（≤5s 内完成加载进入，ac1）。
2. 引导开垦第 1 块菜园地块（已预置 4 块可用，引导演示 1 块）。
3. 播种胡萝卜 ×4 块（每块 1 袋，种子 5 金币/袋，共 20；初始金币 60 足够）。
4. 等待 20s 生长（期间展示生长三阶段：发芽 → 抽叶 → 成熟呼吸光）。
5. 收获 8 根胡萝卜（收获动效 + `harvest` 音效）。
6. 打开订单板，交付首单「胡萝卜 ×5」→ 26 金币 + 12 经验（`coin` 音效 + 经验条动效）。
7. 剩余胡萝卜直售集市 → 12 金币；任务 q1 完成，弹出「目标达成」庆祝横幅。

**引导总时长目标 ≈ 150s，完成后玩家金币 ≈ 50、经验 ≈ 20，直指 Lv2（30 exp）解锁鸡舍。**

### 1.3 任务五阶段（quest 链，覆盖需求「任务目标 ≥5 阶段」）

| id | 阶段 | 目标 | 奖励 | 引导指向 |
|---|---|---|---|---|
| q1 | 第一次收成 | 收获任意作物 ×1 | 30 金币 + 10 经验 | 种植循环 |
| q2 | 小有积蓄 | 累计持有金币 ≥150 | 40 金币 + 15 经验 | 售卖/订单 |
| q3 | 开个养殖场 | 建造鸡舍（120 金币） | 1 枚鸡蛋 + 20 经验 | 养殖 |
| q4 | 加工增值 | 工坊产出第 1 个蛋糕 | 60 金币 + 25 经验 | 工坊/解锁链 |
| q5 | 悠闲时光 | 建造任意 1 座休闲天地设施 | 100 金币 + 30 经验 | 长线目标/治愈氛围 |

任务顺序串行解锁（q(n+1) 在 q(n) 完成后显示），全程可离线推进度（存档恢复）。

### 2.3 交互与镜头约定

- 点击地块/设施 = 弹出**底部动作条**（播种选种/收获/升级），不做右键菜单；所有操作 1 次点击内可达。
- 生产进度：地块上方悬浮圆形进度环（收获可收时呼吸高亮）；禽舍/工坊用顶部横条进度。
- 镜头：固定全景（v1 不做缩放/平移），保证移动端竖屏（390×844）下 UI 不遮挡生产区（HUD 折叠为两行）。

### 4.2 光照与氛围

- 全局 `CanvasModulate #FFF4E0`（暖白罩染），v1 固定「清晨→午后」柔光，不做日夜硬切换。
- **无实时阴影**：所有实体用椭圆假阴影（黑 α0.18，宽=实体宽 ×0.8）。
- 成熟作物呼吸光：`modulate` 在 ±5% 亮度间以 1.6s 周期正弦呼吸，提示「可收获」但不催促。
- 粒子上限：喷泉水花/收获叶片 ≤ 24 粒/发射器，禁用屏幕级全屏特效。

### 4.3 动效规格（反馈即治愈，全部 ≤400ms）

| 场景 | 动效 | 时长/缓动 |
|---|---|---|
| 播种 | 种子下落 + 土色微闪 | 200ms ease-out |

| 升级/建造 | 涟漪扩散 + 横幅滑入 | 300ms |
| UI 过渡 | 淡入 + 8px 上移 | 150~200ms ease-out |

### 4.4 字体与适配

- 字体：`NotoSansSC-Regular.otf`（工程已内置），正文 16px、HUD 数字 20px、标题 24px。
- 设计分辨率 1280×720，`canvas_items/expand` 拉伸；适配 1920×1080 桌面与 390×844 移动竖屏（ac1 适配项）。

## 5. 音效规格

### 5.1 音频总线

```
Master ── BGM（-12dB，可单独静音）
       ── SFX（触发音，峰值 ≤ -6dBFS）
       ── Ambience（自然白噪音层，-20 ~ -24dB）
```

### 5.2 BGM

- 曲目 `bgm_meadow`：轻量治愈系循环，BPM 70~85，五声音阶（宫调式），配器 = 钢琴 + 木吉他 + 弦乐垫。
- 无缝循环、响度 ≈ -18 LUFS；默认开启，首次交互后播放（浏览器自动播放策略）。

### 5.3 自然白噪音层（Ambience）

| 层 | 规格 |
|---|---|
| 鸟鸣 | 随机触发，间隔 8~20s，-20dB，禁用高音频段尖啸 |
| 风声/叶响 | 持续循环，-24dB |
| 禽舍鸡鸣/鸭叫 | 事件触发（进入禽舍视野/产蛋），-16dB，轻快不刺耳 |

### 5.4 触发音效表（命名与工程资产一致）

| 事件 | 音效 | 音高规则 |
|---|---|---|
| 播放/点击 UI | `click` / `confirm` | 固定 |
| 播种 | `plant` | 固定 |
| 收获 | `harvest` | 按作物解锁档位 +0/1/2 半音，制造成长感 |
| 金币结算 | `coin` | 连续入账按 +1 半音阶梯（≤5 级） |
| 升级/建造完成 | `upgrade` | 固定 |
| 余额不足/非法操作 | `fail` | 低音、短、不刺耳（禁止急刹音效） |
| 禽舍 | `cluck`（鸡）/`quack`（鸭）/`honk`（鹅） | 随机 ±1 半音 |

全部 SFX 44.1kHz WAV，单发峰值 ≤ -6dBFS；任一音效不得引起波形削波（契约断言项）。
