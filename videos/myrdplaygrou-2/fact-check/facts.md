## 四、冲量定理与缓冲（"以柔克刚"的物理核心）

| ID | 论断 | 分级 |
|---|---|---|
| F-13 | 冲量-动量定理 **F̄ = Δp/Δt**：动量变化一定，作用时间越长，平均力越小 | A |
| F-14 | 比例结论（可机械证明）：**接触时间 ×10 → 平均力 ×1/10**；×100 → ×1/100 | A |
| F-15 | 演示示例（前提必须声明"假设"）：350 g 瓶从 1 m 落下（p=1.55），**假设**作用 5 ms → 平均力 ≈310 N；拉长到 50 ms → ≈31 N | A |
| F-16 | 同口径量级对比：310 N 约为鸡蛋壳破裂上限 50 N 的 **6.2 倍**（动态假设 vs 准静态阈值，只作量级对比） | A |
| F-17 | 母鸡蛋壳准静态压缩可承受 **30–50 N**，壳厚仅 350–450 µm；动态冲击阈值另依条件 | B |
| F-18 | 文献实测参照：200 g 钢球 50 cm 落泡沫峰值压强 10.1 MPa，垫 2–3 层气泡膜 → 2.1 MPa，**降约 79%**（复算 79.2%） | B |
| F-19 | 层数收益递减：1 层 ≈ 加速度降到 1/2.85，3 层 1/3.5，4 层 1/3.6——多垫不再等比例增益 | B |
| F-20 | 机理：密闭气泡 = 微型气垫弹簧——气体压缩吸能 + 力摊到更大面积/更长时间；剧烈冲击下气泡破裂属塑性耗散（能量不弹回） | B |
| F-21 | 缓冲性能有专门测法：**ASTM D1596**（动态落标冲击，产出 cushioning curve） | B |

## 旁白禁用措辞（红线）

1. ❌「气泡膜能挡住任何冲击」——无文献支持（F-19 收益递减、F-20 气泡破裂即失效路径）
2. ❌「实测接触时间 5 ms / 50 ms」——那是**假设参数**（F-15），只能以"假设"引入
3. ❌「鸡蛋只能承受 50 克」——30–50 **N 是力**不是质量（F-17），换算错误是物理硬伤
4. ❌「落地速度 4.43 m/s 为实拍测速」——那是真空口径公式值（F-05/F-07）
5. ❌「气泡膜是 Paul Hogan 发明的」——发明人是 **Fielding 与 Chavannes**（F-22；Paul Hogan 是澳大利亚演员）
6. ❌ 把 F-18「压强降幅 79%」与 F-19「加速度衰减倍数」混成一个数字或互相换算

## 口径注记

- 所有「从 1 m / 0.5 m 落下」均为自由落体假设，非实拍镜头实测速度
- 玻璃瓶动量/动能按 **350 g 中段**口径计算；改瓶重则随质量线性重算，比例结论（F-14）不受影响
- 动量（kg·m/s）与动能（J）是两个量，旁白不可混称「力量」
- 「平均冲击力」（F̄=Δp/Δt）是时间平均，不是峰值力；F-18 的峰值压强是另一口径
