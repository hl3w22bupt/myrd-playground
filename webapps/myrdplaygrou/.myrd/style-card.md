# 《今日汇率》风格卡

> 基准：目标「创作决策」固化口径 —— 清新明亮、浅色/白色基底、清新主色（薄荷绿/天蓝色系方向）。
> 本卡为 styles.css CSS 变量的唯一事实来源；微调仅限明度/饱和度，不得换风格方向。

## palette

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#f4fbf9` | 页面基底（薄荷调浅底，非纯白，柔和不刺眼） |
| `--surface` | `#ffffff` | 卡片面 |
| `--primary` | `#14b8a6` | 主色（薄荷绿）：主按钮、焦点、强调 |
| `--primary-strong` | `#0d9488` | 主色按压态 |
| `--primary-soft` | `#ccfbf1` | 主色弱化面：标签、图表辅助 |
| `--sky` | `#38bdf8` | 辅助色（天蓝）：趋势图线、次级强调 |
| `--ink` | `#0f2e2b` | 正文墨色（对 `--bg` 对比度 ≥ 12:1） |
| `--ink-soft` | `#5b7470` | 辅助信息（对白底 ≥ 4.6:1） |
| `--up` | `#e11d48` | 区间上涨（中式红涨） |
| `--down` | `#059669` | 区间下跌（绿跌，与主色同族区分度足够） |
| `--line` | `#d7e8e4` | 分隔线/描边 |
| `--warn` | `#b45309` | 数据滞后提示（琥珀，唯一警示色） |

## ui

- 字号三档：换算结果 44–56px（首要视觉焦点，明显大于一切正文）→ 标题/区块题 20–24px → 正文 16px / 辅助 13px；正文行高 ≥ 1.5。
- 布局：移动端单列（<768px），内容区左右留白 ≥ 16px，卡片圆角 16px、留白宽松（卡片内边距 20–24px）；桌面端 ≥1200px 双列（换算卡 + 趋势卡并排），最大内容宽 1080px 居中。
- 换算卡为第一视觉层级：结果数字用 `--primary` 深一档的墨绿描字重 700，其余信息全部弱化其下。
- 触控目标 ≥ 44×44px；按钮/输入框圆角 12px，三态齐全（默认/悬停/激活）。
- 图表：SVG 折线 2px 圆角端点，面积渐隐填充（主色 8% 透明度），数据点 7 天 7–8 个 / 30 天 10–12 个抽样标注。
- 图标一律内联 SVG（M1 网关只透传文本，禁止外链位图字体/图片）。

## 禁忌反例

- 禁止暗色背景、大面积深灰/黑色块（清新明亮是方向红线）。
- 禁止换算结果与正文同字号（结果必须一眼可辨为大字号焦点）。
- 禁止横向溢出：任何元素不得宽于视口，`scrollWidth ≤ clientWidth`。
- 禁止弹窗/遮罩阻断核心闭环（选币种 → 输金额 → 看结果 → 看趋势 单页完成）。
- 禁止外链图片/位图图标/图标字体（二进制会被网关 502）。
- 禁止红绿作为唯一涨跌区分通道：涨跌必须「颜色 + 符号(▲/▼) + 百分比文字」三重编码。
