# 新线风格卡模板（预置件② · 美术线产出物模板）

> 用法：第二产品线风格定稿时复制本模板逐项填写；**每项必须给「值 + 一句理由 + 反例（禁什么）」**。
> 纪律：风格卡 = 主观取向的固化容器，锁「视觉一致性」，不锁「好不好看」（观感终裁归主人人工验收）。
> 填写后落点：`games/<new-line>/assets/style/style-card-v1.md` + 对应色板 JSON（生成器输入单源）。

## 四要素

### 1. 色板（Palette）
- 值：主色 `#______` · 强调色 `#______` · 冷/暖反馈双色 `#______ / #______` · 底色 `#______`（合计 ≤9 token，九键判例承自 g2-blocks UI token）
- 理由：______（对齐品类情绪，如割草=高对比暖强调）
- 禁：超出色板的新 hex 直接入码（必须走色板 JSON 单源 + 双门禁 ΔE 阈值，判例 ac-12）

### 2. 字体（Type）
- 值：正文/数字______（系统栈或单一自托管字重 ≤2 档）· 数字等宽：是/否
- 理由：______
- 禁：多字体混排、运行时网络字体拉取（离线可玩红线）

### 3. 形状语言（Shape Language）
- 值：圆角半径档位 ___/___/___ · 轮廓（描边 有/无 · 宽度 __）· 实体剪影原则：______
- 理由：______（与玩法读屏相关：实体必须一眼可分类）
- 禁：同屏剪影混淆对（形状不可辨即读屏缺陷）

### 4. 动效原则（Motion）
- 值：挤压/回弹曲线 token（名称 + ms 档位）· 震屏（开/关 · 幅度档）· 粒子（密度档 + 同屏硬顶 ___）
- 理由：______（动效服务反馈可读性，非装饰）
- 禁：无频控的常驻动效；动效数值绕过 numeric 冻结面（一律走 spec 单源，判例 e-feel 组）

## 一致性门禁（美术产出验收机判面）

- 色板双门禁：全仓 hex 溯源色板单源 + 相似色对 ΔE ≥ 阈值（判例 g2-blocks ac-11/ac-12）
- 动效数值：与 spec numeric 面逐字节一致（生成器产数据文件，零手抄）
- 截图证据：每批美术产出附同批 `buildSha256` 的实机截图 manifest（判例 v13-shots）
