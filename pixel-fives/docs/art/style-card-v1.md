## 0. 使用纪律（派生而非重编）

1. 每个资产的产出提示词 = **本卡全文锁定项（不许改写）+ 该资产差异段（只写差异）**。
2. 禁止逐图另编形容词；禁止引入卡外色值、卡外光源、卡外比例。
3. 同队资产必须同骨架：A03（霜蓝）= A02（赤焰）网格逐像素换色派生，不重画。
4. 风格漂移（像素风混入手绘/平滑插值/卡外色）按缺陷处理，QA 可直接打回。

## 1. 调色板 —— 20 色全局锁定

> 全局共 20 色 + 透明。**禁止使用表外色值**；队伍色每队仅 3 阶（主/暗/亮）。

| 记号 | HEX | 用途 |
|---|---|---|
| `K` | `#1A1626` | 最深线稿/轮廓替代纯黑、球面五边形纹、眼睛、球靴 |
| `S` | `#2E2A44` | 内描边/暗部描边（禁用 `#000000`） |
| `d` | `#256B3A` | 草地暗条纹（修剪纹） |
| `g` | `#2E7D46` | 草地基色 |
| `l` | `#3B9457` | 草地亮纹理 |
| `w` | `#F4F1E8` | 场地白线、球体亮面、UI 主文字（暖白，非纯白） |
| `v` | `#C9C4B4` | 球体暗面、球网、中性灰 |
| `p` | `#A8A394` | 门柱暗面、网影 |
| `e` | `#E8E4D8` | 门柱/门框亮面 |

| `R` | `#A8281C` | 赤焰暗阶 |

| `y` | `#5C8FF0` | 霜蓝亮阶 |

调色板纪律：
1. 队伍色互换只允许 `r↔b`、`R↔B`、`x↔y` 三组映射（脚本校验）。
2. 中性色（`w/v/p/e/K/S`）全队共用，不得队伍化。
3. 每个资产实际用色必须在 manifest 的 `palette_used` 中登记，`gen-assets.mjs` 负责校验 ⊆ 全局 20 色。

## 2. 光照

- **单一光源：左上 45°**。全游戏唯一光源方向，不得按场景改。
- 每个精灵**最多 3 阶明暗**（亮阶/主色/暗阶），高光不超过 2px 宽。
- **硬边像素过渡**：明暗交界走像素阶梯；禁止渐变、禁止抗锯齿、禁止软阴影。
- 接地投影**不画进精灵**：由程序以 `K` 色 50% alpha 椭圆统一绘制（精灵内出现投影视为越权）。
- 球门内侧网面允许整面降 1 阶（`v`→`p`）表现背光，属本条特例。

---

## 3. 线条

- **内描边 1px**：受光侧用 `S`，背光侧用 `K`；**外轮廓禁止纯黑 `#000000`**。
- 形状转折用**像素阶梯**表达；禁止 1px 斜线抗锯齿（禁止中间色过渡像素）。
- 场地白线恒为 1px `w`；角球弧/中圈允许 1px 阶梯圆。

---

## 4. 比例与规格

- **视角：¾ 俯视（top-down ¾）**；角色统一**侧视朝右**，反向 = 水平镜像，**禁止旋转精灵**。
- **公度网格：16px**。所有资产尺寸为 16 的公度或其半格（8px）。
- 球员：**16×16**，Q 版 ≈2.5 头身（头 5px、躯干 4px、腿 5px，含 2px 地面余量）。
- 足球：**8×8**（半格），带 4 帧滚动。
- 球门：**32×24**，左右两向 = 同图镜像。
- 球场 tile：**16×16**。
- UI 面板：16px 公度九宫格；圆角 2px 阶梯。
- **导出纪律**：整数倍缩放（2x/4x）导出；禁止非整数缩放、禁止平滑插值（`image-rendering: pixelated`）。

**动画帧率基准**：角色动画基准 **12fps**（A06 终裁锚点：9 帧@12fps=0.75s）；循环动画帧率在 manifest 按段登记（idle 4fps / run 12fps / roll 12fps）。

| A06 | `a06-kick-shot` | 动画 | **9 帧@12fps = 0.75s（终裁锁定）** | 16×16 | 双队共用骨架（换色同 A03 规则） | `entities/player`（shoot 动作） |

A06 出脚约定：`contact_frame = 3`（0 基，第 4 帧 ≈250ms）为**视觉接触帧**；判定/出球由程序在输入后即时触发（红线 `input_to_shot_latency_ms ≤ 50`），动画纯为视觉反馈、不阻塞判定——该约定随本卡一并送批。

A07 范围纪律：**比分数字不占美术位图预算**，用系统像素字体渲染；A07 只出面板九宫格 + 队色标签 + 计时槽。

A08 归属说明：`goal_sfx_at_s` 字段属策划案 v1.2（主策划落文），美术侧默认触发偏移 **0.0s**（进球判定即触发，不加延迟）。

## 7. 体积预算红线

- 资产总量 **≤ 1,572,864 bytes（1.5MB）**（微信主包 ≤4MB 红线内，为代码/音频余量让位）。
- 体检方式：`node pixel-fives/tools/gen-assets.mjs` 自动汇总全部产物字节数，**超线即 exit 1**。
- 网格源（`.grid`）为版本控制真源，导出 PNG 为构建产物；双方体积均计入预算表。
