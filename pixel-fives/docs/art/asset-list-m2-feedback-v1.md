## 3. 性能数字并表（美术侧承诺值，程序批注见 docs/dev/feasibility-m2-feedback-v1.md）

| 项 | 承诺值 | 依据 |
|---|---|---|
| 动效时长 | 4 项全部 ≤300ms（125–250ms） | v1.3 numeric `feedback.anim_max_ms` 红线 |
| 反馈首帧 | 音效通道 0ms（同 tick 排程）；动画通道 ≤1 帧（≤42ms） | v1.3 `red_line.feedback_first_frame_ms ≤100` 留 2.4× 余量 |
| 预算增量 | 视觉 ≤12KB + 音频 ≤15KB ≈ **27KB**；现用量 15,532B → 增后 ≈43KB / 1.5MB（占用 2.7%） | acc-08 闸门每批复跑 |
| 粒子上限 | 同屏 A09 粒子 ≤24 sprites（走既有对象池 entityPool 模式） | 60fps 预算（程序并表核对） |
| 缩放纪律 | 整数倍缩放（16px 公度），禁平滑插值 | 风格卡锁定 |

## 4. 量产顺序（批准后）

A09（进球，核心反馈）→ A13/A14（音，首帧通道）→ A10（失球）→ A11（尘点）→ A12（火花，可砍项）。
每批过 `gen-assets.mjs` 预算闸门 + QA 风格漂移复检后才放下一批。
