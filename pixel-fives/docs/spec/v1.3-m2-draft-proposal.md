## 1. 范围与口径

### 1.1 范围锁定（主人 9/22 指令）
**只做三件事：反馈表现力 + bot 曲线 + onboarding。** 核心循环与数值单源（constants.js 玩法值）不动，
确定性红线延续（60Hz + mulberry32、core 零 `Math.random`/`Date.now`）。

### 1.2 不做（冻结项延续 + M2 追加）
v1.2 负面清单 7 条全延续；M2 追加不做：在线联机/排行榜对局、内购/广告、多模式/联赛、
微信/抖音平台化（**移列 M3 候选**，见 1.3）。

### 1.3 与 9/12《M2 预排·微信/抖音双平台化》的关系（scope 决策记录 · 如实）
9/12 预排稿把 M2 定义为平台化；9/22 主人指令将 M2 锁定为「反馈表现力 + bot 曲线 + onboarding」。
**以 9/22 指令为准**；预排稿是里程碑预排（文头自述「非 DoD 拍板」），无版本链问题，标 superseded-by-20260922，
平台化预排内容原样移列 M3 候选清单，不删除不篡改。

## 2. M2 指标量化（全部入 numeric，逐条带复验方式 → QA 复审单）

| 指标 | 键 | 目标 | 复验方式（可核对） |
|---|---|---|---|
| 单局时长 | `match.duration_cap_s` | ≤180s 不回退（现 90s） | bot-sim duration_in_range 比率 + full-match 冒烟 |
| 场均进球 | `bot_curve.avg_goals_range` | ∈[2,4] 不回退（M1 基线 5.52） | `bot-sim --profile onboarding --seeds 42..141 --json`（M2 交付 profile 扩展）逐场报告核算 |
| 反馈首帧 | `red_line.feedback_first_frame_ms` | ≤100ms | headless 同 tick 排程断言（acc-10 落点测试）+ 真机抽测 |
| 动效上限 | `feedback.anim_max_ms` | ≤300ms（仅 M2 新增反馈动效；A06/庆祝为 M1 已批不适用） | 逐动效时长断言（acc-11 落点测试） |
| 震动 | `feedback.haptic_levels` | 3 级（轻触1/进球2/失球3） | 映射表断言（acc-12）+ 真机手感复核 |
| 首局胜率 | `bot_curve.first_match_win_rate` | 65–75%（onboarding 档） | 本地埋点周报（acc-13/14 口径）；win rate = 首局获胜会话 / 首局完成会话 |
| 长期胜率 | `bot_curve.long_term_win_rate` | ≈50%±5%（ranked 档） | 同上，按周窗口滚动 |
| 教学时长 | `onboarding.tutorial_time_s` | ≤30s（中位数） | 埋点还原首触→首进球引导链时长（acc-14） |
| 首局完成率 | `onboarding.first_match_complete_rate` | ≥90% | **样本口径：安装后 48h 内新玩家首局，开始→终局达成率；自然周聚合；周样本 ≥200 方判定，不足则本周不出结论（不伪造）** |
| 埋点 | `telemetry.dual_caliber` | 双口径降级兜底 | 降级路径断言（acc-15）：平台不可用→本地环形缓冲，schema 逐字一致，重启不丢 |
